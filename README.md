## 🔍 How It Works

This model:
1. Fetches live odds from multiple sportsbooks via The Odds API
2. Analyzes team performance over the last 10 games
3. Factors in home/away splits and momentum
4. Compares Vegas lines to model predictions
5. Makes picks when it finds significant edges (3+ points)
